# Retail-Sales-Analysis
Exploratory Data Analysis (EDA) on retail sales data using Python and Pandas.

# Retail Sales Performance Analysis 📊

## Project Overview
This project analyzes 1,000 retail transactions to identify key revenue drivers and regional performance using Python.

## Key Insights
* **Top Region:** The **North** region is the highest performer, generating over 1.36M in sales.
* **Top Performer:** **David** led the sales team with 1.14M in total revenue.
* **Data Quality:** Conducted a data audit confirming zero null values across 14 columns.

## Tech Stack
* **Language:** Python 3.13
* **Environment:** Anaconda & VS Code
* **Libraries:** Pandas (Data Manipulation), Matplotlib (Visualization)
